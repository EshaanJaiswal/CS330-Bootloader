# AGENTS.md

This file documents the use of AI assistance in this project, as permitted by the course policy.

## AI Tools Used

| Tool | Purpose |
|------|---------|
| LLM-based AI assistant using FreeLLMAPI and Claude Code as Agent Harness | Project planning, architecture guidance, code assistance, and debugging |

## Policy

AI assistance is **permitted** for this project per Prof. Balu's guidelines. The student is expected to **understand and explain** all code and design decisions independently.

## How AI Was Used

1. **Project Planning** — AI was used to help structure the project plan, identify phases, and assess risk areas.
2. **Architecture Guidance** — AI provided guidance on the UEFI boot flow, the Linux Boot Protocol, and gnu-efi usage patterns.
3. **Code Assistance** — AI assisted with writing bootloader source code, Makefile configuration, and debugging UEFI-specific issues.
4. **Documentation** — AI helped draft documentation and format the project plan.

## What The Student Did Independently

- All final design decisions (language choice, feature selection, architecture)
- Understanding and explaining the UEFI specification and Linux Boot Protocol
- Testing on QEMU and (if applicable) real hardware
- Debugging runtime issues (triple faults, ExitBootServices failures, memory map errors)
- Presenting and defending the project to the professor

## Transparency Note

Every commit in this repository reflects the student's understanding of the code at that point. AI was used as a learning accelerator, not as a replacement for understanding.
